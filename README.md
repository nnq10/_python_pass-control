## О проекте

`Контроль пропусков` помогает вести локальную базу пропусков, быстро проверять QR-коды на КПП, печатать бумажные пропуска по шаблонам и контролировать действия пользователей. Приложение работает локально, хранит данные в `data/` и не требует внешнего сервера.

Проект заточен под реальные рабочие сценарии: одноразовые пропуска на 1-10 дней, временные на месяц, полугодовые с обязательной фотографией, печать на A4 и администрирование профилей доступа.

## Возможности

| Раздел | Что умеет |
| --- | --- |
| Сканер | Проверка QR-кодов, разные звуки для разрешенного и запрещенного прохода, крупная карточка результата |
| Одноразовые | Пул QR-кодов, выдача на 1-10 дней, возврат QR для повторного использования, без фотографий |
| Временные | Пропуска на месяц, поиск, фильтры, статистика активных и неактивных, без фотографий |
| Полугодовые | Пропуска на 6 месяцев с обязательной фотографией |
| Печать | Отдельные шаблоны для типов пропусков, QR в шаблоне, печать нескольких пропусков на A4 |
| Редактор шаблонов | Настройка координат текста, QR и фото прямо из приложения |
| Справочники | Избранные округа, подразделения и звания с автоподстановкой |
| Пользователи | Роли, гибкие права на вкладки, защита последнего администратора |
| Аудит | История действий по пропускам и пользователям |
| Обслуживание | Проверка целостности базы, очистка лишних файлов, корзина и резервные копии |

## Быстрый старт

```powershell
git clone https://github.com/nnq10/_python_pass-control.git
cd _python_pass-control

python -m venv .venv
.\.venv\Scripts\Activate.ps1

pip install -r requirements.txt
```

Создайте первого администратора:

```powershell
@'
from app.services.auth import upsert_user
upsert_user("admin", "Администратор", "admin", "admin")
'@ | python -
```

Запустите приложение:

```powershell
python pass_control.py
```

После входа под `admin / admin` лучше сразу поменять пароль в разделе пользователей.

## Требования

- Python 3.10 или новее
- Windows, Linux или macOS с графическим интерфейсом
- Камера, если нужна съемка фото или работа со сканированием через камеру

Зависимости:

- `customtkinter` - современная оболочка интерфейса
- `Pillow` - обработка изображений, фото и шаблонов
- `qrcode[pil]` - генерация QR-кодов
- `openpyxl` - импорт и экспорт Excel
- `opencv-python` - работа с камерой

## Данные приложения

Рабочие данные создаются локально в папке `data/`:

```text
data/
  passes.db       # база пропусков, журналов и справочников
  users.json      # пользователи, роли и хеши паролей
  settings.json   # настройки приложения
  photos/         # фотографии для полугодовых пропусков
  qrcodes/        # QR-коды
  templates/      # пользовательские шаблоны печати
  prints/         # готовые PNG/PDF для печати
  sounds/         # пользовательские звуки сканера
  backups/        # резервные копии
  app.log         # журнал работы
```

Содержимое `data/` не коммитится в Git. В репозитории остается только `data/.gitkeep`, чтобы папка существовала после клонирования.

## Печать

Пропуска печатаются по отдельным профилям:

- `Одноразовые` - 1-10 дней, без фото
- `Временные` - месяц, без фото
- `Полугодовые` - 6 месяцев, с фото

Поддерживается печать нескольких пропусков на одном листе A4. Размер одного пропуска рассчитан под `10 см x 6 см`.

```text
app/
  core/                  # настройки, пути, логирование
  pages/                 # экраны приложения

  ui/                    # общие UI-виджеты
tests/                   # автотесты
data/                    # локальные данные, не публикуются
```

## Безопасность

Не публикуйте `data/` в открытом репозитории. Внутри могут быть персональные данные, фотографии, база пропусков, настройки, звуки и файлы пользователей.

Пароли не хранятся открытым текстом. Для пользователей используется PBKDF2-SHA256 с солью и большим числом итераций.
