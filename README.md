## О проекте

`Контроль пропусков` помогает вести локальную базу пропусков, быстро проверять QR-коды на КПП, печатать бумажные пропуска по шаблонам и контролировать действия пользователей. Приложение работает без внешнего сервера: база, QR-коды, фотографии, шаблоны, звуки и резервные копии хранятся рядом с программой в папке `data/`.

Проект рассчитан на реальные рабочие сценарии:

- одноразовые пропуска на 1-10 дней;
- месячные пропуска без фотографий;
- полугодовые пропуска с обязательной фотографией;
- печать бланков и QR-книг на A4;
- перенос месячных и полугодовых пропусков на ноутбук КПП через пакет `.pcpkg`;
- разграничение доступа пользователей по вкладкам.

## Возможности

| Раздел | Что умеет |
| --- | --- |
| Сканер | Быстрая проверка QR-кодов, разные звуки для активного и неактивного пропуска, крупная карточка результата |
| Одноразовые | QR-книги по 500 кодов, выдача на 1-10 дней, запрет повторного использования QR, архивирование законченной книги |
| Месячные | Пропуска на 30 дней, поиск, фильтры, статистика активных и неактивных, печать без фотографии |
| Полугодовые | Пропуска на 180 дней, обязательная фотография, печать и проверка заполненности данных |
| Печать | Отдельные шаблоны для типов пропусков, QR в нужных местах, сохранение PNG/PDF, печать нескольких пропусков на A4 |
| QR-книга | Книжная ориентация, корешок и пропуск по 10x7 см, QR-код на обеих сторонах, отступ под сшивание |
| Редактор шаблонов | Настройка координат, размера текста, QR и фото; шрифт `Times New Roman` для печатных полей |
| Импорт и обмен | Импорт Excel, экспорт и импорт пакетов КПП `.pcpkg` для месячных и полугодовых пропусков |
| Справочники | Избранные округа, подразделения и звания с автоподстановкой |
| Пользователи | Роли, гибкие права на вкладки, защита последнего администратора |
| Аудит | История действий по пропускам, пользователям, печати и пакетам КПП |
| Обслуживание | Проверка целостности базы, очистка лишних файлов, корзина и резервные копии |

## Обмен с КПП

Для ситуации, когда месячные и полугодовые пропуска оформляются в кабинете, а ноутбук со сканером стоит на КПП, добавлен обмен пакетами:

1. На рабочем компьютере оформляются месячные и полугодовые пропуска.
2. В разделе импорта нажимается `Экспорт для КПП`.
3. Программа создает файл `.pcpkg` с базой нужных пропусков, QR-кодами и фотографиями полугодовых.
4. Файл переносится на ноутбук КПП.
5. На КПП нажимается `Импорт пакета КПП`.
6. Перед импортом программа показывает, сколько месячных и полугодовых пропусков найдено, и делает резервную копию текущей базы.

Одноразовые пропуска в такие пакеты не входят: они живут отдельными QR-книгами, чтобы каждый QR использовался только один раз.

## Одноразовые пропуска

Одноразовые пропуска работают через книги QR-кодов:

- одна книга содержит до 500 QR-кодов;
- QR-код после выдачи считается использованным и не возвращается в пул;
- когда книга заканчивается, программа предлагает сохранить ее данные перед созданием новой;
- печатная форма рассчитана на бумажный бланк с корешком;
- данные человека можно вести в базе, но на бумажной форме одноразового пропуска печатаются только QR-коды.

## Быстрый старт

```powershell
git clone https://github.com/nnq10/_python_pass-control.git
cd _python_pass-control

python -m venv .venv
.\.venv\Scripts\Activate.ps1

pip install -r requirements.txt
```

Создайте первого администратора:

```powershell
@'
from app.services.auth import upsert_user
upsert_user("admin", "Администратор", "admin", "admin")
'@ | python -
```

Запустите приложение:

```powershell
python pass_control.py
```

После входа под `admin / admin` рекомендуется сразу поменять пароль в разделе пользователей.

## Требования

- Python 3.10 или новее;
- Windows, Linux или macOS с графическим интерфейсом;
- камера, если нужна съемка фото или сканирование через камеру;
- принтер, если используется прямая печать из приложения.

Основные зависимости:

- `customtkinter` - современный интерфейс поверх Tkinter;
- `Pillow` - обработка изображений, фото и шаблонов;
- `qrcode[pil]` - генерация QR-кодов;
- `openpyxl` - импорт Excel;
- `opencv-python` - работа с камерой.

## Данные приложения

Рабочие данные создаются локально в папке `data/`:

```text
data/
  passes.db       # база пропусков, журналов и справочников
  users.json      # пользователи, роли и хеши паролей
  settings.json   # настройки приложения
  photos/         # фотографии для полугодовых пропусков
  qrcodes/        # QR-коды
  templates/      # пользовательские шаблоны печати
  prints/         # готовые PNG/PDF для печати
  sounds/         # пользовательские звуки сканера
  assets/         # иконка приложения и дополнительные ресурсы
  backups/        # резервные копии
  app.log         # журнал работы
```

Содержимое `data/` не коммитится в Git. В репозитории остается только `data/.gitkeep`, чтобы папка существовала после клонирования.

## Печать

Пропуска печатаются по отдельным профилям:

- `Одноразовые` - 1-10 дней, без фото, QR на корешке и основной части;
- `Месячные` - 30 дней, без фото;
- `Полугодовые` - 180 дней, с обязательной фотографией.

Поддерживается сохранение печатных форм в PNG/PDF, выбор места сохранения, прямая отправка на принтер и печать нескольких пропусков на одном листе A4.

## Сборка EXE

Для сборки portable-версии:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build_exe.ps1
```

Готовая программа появится в:

```text
dist/PassControl/PassControl.exe
```

Для переноса на другой компьютер копируйте всю папку `dist/PassControl`, а не только `PassControl.exe`.

Для установки в `C:\PassControl` и создания ярлыка на рабочем столе:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install_to_c_drive.ps1
```

После такой установки рабочие данные будут лежать в `C:\PassControl\data`.

```text
pass_control.py          # точка входа

app/
  core/                  # пути, настройки, тема, логирование
  pages/                 # экраны приложения
  services/              # база, QR, печать, обмен КПП, бэкапы, аудит, валидация
  ui/                    # общие UI-виджеты
tests/                   # автотесты
data/                    # локальные данные, не публикуются
```

## Безопасность

Не публикуйте папку `data/` в открытом репозитории. Внутри могут быть персональные данные, фотографии, база пропусков, настройки, звуки, QR-коды и файлы пользователей.

Пароли не хранятся открытым текстом. Для пользователей используется PBKDF2-SHA256 с солью и большим числом итераций.

Перед переносом базы, импортом пакетов КПП и обновлением программы рекомендуется делать резервную копию папки `data/`.
