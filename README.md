# Контроль пропусков

Desktop-приложение на Python для учета пропусков, сканирования QR-кодов, импорта из Excel, статистики, управления пользователями и резервного копирования.

## Запуск

1. Установите Python 3.10 или новее.
2. Создайте виртуальное окружение:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

3. Установите зависимости:

```powershell
pip install -r requirements.txt
```

4. Запустите приложение:

```powershell
python pass_control.py
```

## Данные

Рабочие файлы хранятся в папке `data/`:

- `passes.db` — база пропусков и журналов;
- `users.json` — пользователи и хеши паролей;
- `settings.json` — настройки приложения;
- `photos/` — фотографии;
- `qrcodes/` — QR-коды;
- `backups/` — резервные копии.

## Структура проекта

```text
pass_control.py      # точка входа
app/
  core/              # пути, конфиг, логирование
  services/          # БД, пользователи, бэкапы
  ui/                # общие виджеты
  pages/             # экраны приложения
tests/               # тесты критичной логики
data/                # рабочие данные, не коммитятся в git
```

## Бэкапы

Приложение создает автоматический бэкап один раз в день. Администратор может создать бэкап вручную и восстановить данные через настройки. Старые архивы автоматически очищаются, по умолчанию хранятся последние 30.

## Тесты

```powershell
python -m unittest discover -s tests -v
```

## Пользователи

Пользователи управляются из интерфейса администратора. Пароли не хранятся открытым текстом: используется PBKDF2-SHA256 с солью.
